### 📂 Proyectos Destacados

#### 💰 [Wallet-API](https://github.com/Kaistendev/WalletAPI)
**Sistema de gestión financiera de alta precisión.**
* **Core:** API RESTful con **TypeScript** y **Prisma**.
* **Lo más técnico:** Implementación de transacciones atómicas para garantizar integridad en transferencias y manejo de precisión monetaria con `Decimal.js` (evitando errores de punto flotante).
* **Seguridad:** RBAC (Control de acceso por roles) y validación estricta con **Zod**.

#### 🏢 [RRHH API](https://github.com/Kaistendev/Human-Resources-API)
**Backend modular para gestión de capital humano.**
* **Core:** Node.js con **Sequelize** y **PostgreSQL**.
* **Lo más técnico:** Diseño de una base de datos relacional compleja que gestiona contratos, asistencia y permisos. Estructura de proyecto organizada en capas (Controller-Service-Repository) para alta mantenibilidad.

#### 🎮 [Rank API](https://github.com/Kaistendev/Rank-Api)
**Motor de ranking y caché de alto rendimiento para E-sports.**
* **Core:** API REST escalable desarrollada con **Node.js** y **Redis**.
* **Lo más técnico:** Implementación de *Sorted Sets* para clasificaciones en tiempo real con complejidad $O(\log N)$. Incluye gestión de persistencia efímera mediante TTL, validación estricta de esquemas con **Zod** y una arquitectura testeada con **Jest/Supertest** bajo un enfoque de integración continua.
